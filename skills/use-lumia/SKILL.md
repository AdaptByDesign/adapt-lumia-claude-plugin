# Use Lumia

Discover the connected Lumia MCP tools relevant to the user's request. Use their
current descriptions, parameter schemas and returned instructions to guide the
work, including any required preparation or confirmation. These are the source
of truth for available capabilities and how to use them.

For example requests and useful deliverables, see
[workflow examples](references/workflows.md). Select only what serves the user's
request; examples do not establish that a capability is available to every account.
